LIVE × SHADOW · real traffic, zero risk

Your rewrite says it works. Specter makes it prove it.

A distributed shadow-mode traffic mirror with divergence analysis, written in Go. Every request hits your live service as normal — and a silent copy fires at your shadow service. Specter diffs the two and tells you exactly where they disagree.

Consistent hashing, at cluster scale

Every Specter node sits on a hash ring with many virtual nodes. Each request key (say, X-User-ID) hashes to the nearest clockwise position — deterministic ownership, minimal remapping when nodes join or leave. Inspired by Uber's Ringpop.

cluster node (virtual) request key → nearest clockwise node

Built for real production traffic

🪞

Zero-risk mirroring

The shadow response never reaches the client. Real traffic, no blast radius.

📊

Divergence analysis

Every mismatch is logged and scored into a statistical profile of how your rewrite behaves.

🕸️

Distributed by design

Gossip-based clustering with consistent hashing keeps ownership stable as nodes join or leave.

🗄️

Pluggable storage

BadgerDB for local speed, Postgres for durability — swap backends with one config line.

📺

Live TUI dashboard

A terminal UI polls live divergence stats every second, with drill-down into any mismatch.

🎛️

Configurable sampling

Mirror 1% or 100% of traffic. Store everything, or only the interesting divergences.
